# Python Sorting

## Explanation

Sorting is the process of arranging data in a specific order.

This program demonstrates **Bubble Sort**, which repeatedly compares adjacent elements and swaps them when they are in the wrong order.

## Problem Statement

Write a Python program to sort a list of numbers using the Bubble Sort algorithm.

The program should display the original list, sorted list in ascending order, and sorted list in descending order.

## Features

* Implements Bubble Sort
* Sorts numbers in ascending order
* Displays the sorted list in descending order
* Uses a list to store elements
* Demonstrates nested loops

## How It Works

1. The user enters the number of elements.
2. The elements are stored in a list.
3. Adjacent elements are compared.
4. Elements are swapped when necessary.
5. The process continues until the list is sorted.
6. The sorted list is displayed in ascending order.
7. The list is reversed to display descending order.
